# DeskBot v01 — первое зрение

Первый публичный автономный скетч: робот измеряет расстояние через VL53L0X и
меняет выражение лица на OLED, когда объект приближается.

Связанный контент: `VIDEO-003`.

## Возможности

- состояние `CURIOUS`;
- состояние `HAPPY` при расстоянии до 300 мм;
- гистерезис: возврат в `CURIOUS` после 400 мм;
- анимированное моргание и движение взгляда;
- UTF-8 реплики на OLED;
- диагностика расстояния через Serial.

## Оборудование

- ESP32;
- OLED SSD1306 128×64 по I²C;
- VL53L0X по I²C.

## Подключение этой версии

| Сигнал | GPIO / адрес |
|---|---|
| SDA | GPIO21 |
| SCL | GPIO22 |
| OLED | `0x3C` |
| VL53L0X | `0x29` |

Это историческая распиновка примера, а не обещание совместимости с последними
версиями DeskBot.

## Библиотеки

- U8g2;
- Adafruit VL53L0X.

## Запуск

1. Откройте `DeskBot_v01.ino` в Arduino IDE.
2. Установите библиотеки U8g2 и Adafruit VL53L0X.
3. Выберите вашу плату ESP32 и скорость Serial `115200`.
4. Соберите и загрузите скетч.

## Ограничения

- Один короткий замер может сразу изменить эмоцию.
- Пороги расстояния заданы непосредственно в скетче.
- Код сохранён как публичный исторический пример соответствующего этапа.
