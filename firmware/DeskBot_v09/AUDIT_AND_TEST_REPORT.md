# Аудит и отчёт проверки DeskBot v0.9

## Рефакторинг экрана и APDS-9960 — 16.10.2026

- Устранена недетерминированная инициализация APDS-9960: gesture engine
  запускается с обязательным proximity enable (`PEN`) и полным набором
  настроек FIFO/порогов/усиления.
- Вместо решения по одной паре сырых отсчётов используется нормализованное
  смещение между началом и концом жеста, минимум четыре отсчёта, проверка
  доминирующей оси и пауза от повторного срабатывания.
- OLED ограничен примерно 15 FPS и пропускает передачу неизменившегося
  framebuffer. Это сокращает занятость общей I2C-шины и освобождает время для
  FIFO жестов.
- Полная сборка после изменений успешна: Flash 2311579 / 3145728 байт (73%),
  global RAM 62436 / 327680 байт (19%). Дополнительные 1024 байта RAM — копия
  последнего реально показанного OLED-кадра.
- Аппаратная проверка направлений и подбор порогов всё ещё обязательны: корпус,
  защитное окно и высота руки заметно влияют на APDS-9960.

Дата: 15.10.2026. База: commit
`ffb8f5783366ef0b907e3169105e5b353705a518` (`Add DeskBot v08 voice command firmware`).

## Аудит v0.8

- Главный цикл кооперативный и работает через `millis()`. Долгие операции
  погоды уже изолированы в отдельной FreeRTOS-задаче.
- Общая I2C-шина: SDA GPIO8, SCL GPIO9, 400 кГц. На ней OLED 0x3C, BH1750
  0x23, VL53L0X 0x29, LSM6DS3 0x6B и опциональный APDS-9960 0x39.
- BH1750 читается каждые 500 мс через существующий `RobotSensors`; новый
  экземпляр датчика и новый Wi-Fi manager не создавались.
- `TimeService` единолично запускает Wi-Fi/SNTP и предоставляет локальное
  московское время только после подтверждённой синхронизации.
- INMP441 работает на I2S1 GPIO10/11/12. Захват, SOUND/CLAP, MUSIC и VOICE
  выполняются отдельными задачами/очередями; блокировать `loop()` сетевым
  Tuya-вызовом нельзя.
- MAX98357A использует I2S0 GPIO16/17/18. Конфликтов GPIO новая функция не
  добавляет, поскольку Tuya использует существующий Wi-Fi.
- В v0.8 фактически присутствуют все перечисленные в ТЗ подсистемы: OLED,
  ToF, BH1750, IMU, APDS-9960, звук, INMP441, SOUND/CLAP/MUSIC, wake-word и
  команды, время, погода, состояния и анимации.

## Принятые решения

- Блокирующие операции LynkTuyaLocal выполняются только задачей `tuya` через
  ограниченные очереди. Тайм-аут одной операции — 2500 мс; после ошибки новые
  запросы ограничены backoff 5 секунд, автоматические повторы — 60 секунд.
- Соединение не открывается в каждом проходе `loop()`: оно создаётся только по
  ручному запросу или по подтверждённому решению автоматики.
- Команда ON/OFF держит одно соединение для записи и контрольного чтения DPS 1.
  ACK без совпавшего фактического состояния не считается успехом.
- Автоматическое включение требует валидного NTP-времени. Первичные пороги
  вынесены в `Config.h`; окончательная калибровка оставлена открытой.
- Состояния гирлянды/света отделены от эмоций и сна. Существующая sleep-логика
  по BH1750 сохранена без изменений её правил.

## Проверено

- Актуальный публичный API LynkTuyaLocal 1.0.0 проверен по исходникам commit
  `0a18d59e38937a3f85b00bd3b7c67633cc12d2c6`: `TUYA_V35`, `setTimeout`,
  timestamp-overloads `turnOn`/`turnOff`, `getRelayState` и `closeConnection`.
- Полная прошивка собрана `arduino-cli 1.5.1`, ESP32 core 3.3.12, FQBN
  `esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi`.
- Повторная чистая по изменённым исходникам сборка успешна: Flash 2311211 /
  3145728 байт (73%); global RAM 61412 / 327680 байт (18%).
- В отслеживаемых файлах нет Local Key, Wi-Fi пароля или session key;
  `Secrets.h` и `TuyaSecrets.h` исключены `.gitignore`.

## Не проверено без физического DeskBot

- Реальный handshake и AES-GCM с настроенной локальной розеткой.
- Физические ON/OFF и контроль DPS 1 после потери/восстановления Wi-Fi.
- Пороговые значения BH1750, влияние гирлянды, монитора и настольной лампы.
- Реакция на шторы против выключения лампы: один BH1750 не гарантирует их
  различимость.
- Отсутствие аудио-drop/визуальных задержек при фактическом сетевом тайм-ауте.
- Полная аппаратная регрессия из README. Эти пункты нельзя считать пройденными
  только из-за успешной компиляции.
