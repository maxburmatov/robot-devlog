# DeskBot v02 — сон и пробуждение

Версия добавляет BH1750 и связывает освещённость с поведением робота: в темноте
он засыпает, а при появлении света показывает staged-анимацию пробуждения.

Связанный контент: `VIDEO-004`.

## Возможности

- всё поведение `DeskBot_v01`;
- измерение освещённости через BH1750;
- переход в `SLEEP` ниже 10 lux;
- переход в `WAKE` выше 20 lux;
- отдельная анимация пробуждения;
- distance reaction отключена во время сна и пробуждения.

## Оборудование

- ESP32;
- OLED SSD1306 128×64 по I²C;
- VL53L0X по I²C;
- BH1750 по I²C.

## Подключение этой версии

| Сигнал / устройство | GPIO / адрес |
|---|---|
| SDA | GPIO21 |
| SCL | GPIO22 |
| OLED | `0x3C` |
| BH1750 | `0x23` |
| VL53L0X | `0x29` |

## Библиотеки

- U8g2;
- Adafruit VL53L0X;
- BH1750.

## Запуск

1. Откройте `DeskBot_v02.ino` в Arduino IDE.
2. Установите перечисленные библиотеки.
3. Выберите вашу ESP32 board и Serial speed `115200`.
4. Соберите и загрузите sketch.

## Ограничения

- Точные source/commit, использованные при съёмке VIDEO-004, требуют проверки.
