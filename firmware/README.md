# Версии прошивки DeskBot

Каталоги `DeskBot_vXX` — последовательные публичные snapshots разработки.
Каждый каталог самодостаточен и открывается в Arduino IDE отдельно.

## Правила версий

- имя каталога совпадает с именем главного `.ino`;
- опубликованная версия не получает новые capabilities;
- новая возможность публикуется следующей версией;
- исправления сборки допустимы, но должны быть описаны в README и Git history;
- ссылки из Telegram и Reels ведут на Git tag соответствующей версии.

| Версия | Основная возможность |
|---|---|
| `DeskBot_v01` | ToF и две базовые эмоции |
| `DeskBot_v02` | BH1750, сон и пробуждение |
| `DeskBot_v03` | IMU, движение, pickup, put-down и shake |
