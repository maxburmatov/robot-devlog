# Версии прошивки DeskBot

Каталоги `DeskBot_vXX` — последовательные публичные снимки разработки.
Каждый каталог самодостаточен и открывается в Arduino IDE отдельно.

## Правила версий

- имя каталога совпадает с именем главного `.ino`;
- в опубликованную версию не добавляются новые возможности;
- новая возможность публикуется следующей версией;

| Версия | Основная возможность |
|---|---|
| `DeskBot_v01` | ToF и две базовые эмоции |
| `DeskBot_v02` | BH1750, сон и пробуждение |
| `DeskBot_v03` | IMU, движение, поднятие, постановка и встряхивание |
| `DeskBot_v04` | История присутствия, ожидание, скука и возвращение |
| `DeskBot_v05` | Синхронные реплики и звуки для состояний |
| `DeskBot_v06` | APDS-9960, жесты, часы, погода и runtime mute |
| `DeskBot_v07` | MAX9814, SOUND/CLAP, FFT-анализ музыки и анимированный Dancing |
| `DeskBot_v08` | INMP441, единый аудиотракт и локальные голосовые команды |
| `DeskBot_v09` | Tuya 3.5, диагностика BH1750 и автоматическое включение гирлянды |
| `DeskBot_v10` | Двухосевая шея MG90S и сопровождение цели сканирующим VL53L0X |

### Дополнение DeskBot_v07

В v07 добавлен неблокирующий музыкальный анализатор: ADC continuous 8 кГц,
FFT 256, восемь спектральных полос и визуальное состояние `Dancing`. Старые
окна и пороги `SOUND/CLAP` сохранены через децимацию каждого восьмого отсчёта.
В `Dancing` глаза покачиваются отдельно от эквалайзера, сохраняют реакцию
зрачков на биты, периодически прищуриваются, а возле них появляются
анимированные ноты.
