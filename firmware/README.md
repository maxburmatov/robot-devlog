# Версии прошивки DeskBot

Каталоги `DeskBot_vXX` — последовательные публичные снимки разработки.
Каждый каталог самодостаточен и открывается в Arduino IDE отдельно.

## Правила версий

- имя каталога совпадает с именем главного `.ino`;
- в опубликованную версию не добавляются новые возможности;
- новая возможность публикуется следующей версией;
- исправления сборки допустимы, но должны быть описаны в README и истории Git;
- ссылки из Telegram и Reels ведут на Git-тег соответствующей версии.

| Версия | Основная возможность |
|---|---|
| `DeskBot_v01` | ToF и две базовые эмоции |
| `DeskBot_v02` | BH1750, сон и пробуждение |
| `DeskBot_v03` | IMU, движение, поднятие, постановка и встряхивание |
