# DeskBot v03 — движение и ориентация

Версия добавляет LSM6DS3 и реакции на движение корпуса. Это текущий снимок
разрабатываемой версии для `VIDEO-005`.

## Возможности

- короткое движение → `Surprised`;
- подтверждённое продолжительное движение → `PickedUp` с репликой
  «Поставь меня!»;
- первое отдельное движение после поднятия → `PUT_DOWN` без дополнительного
  `Surprised`;
- сильное движение → `Dizzy`;
- переворот → `UpsideDown`;
- BH1750 управляет сном и пробуждением;
- ToF-переходы требуют трёх последовательных валидных замеров.

## Оборудование

- ESP32-S3;
- OLED SSD1306 128×64 по I²C;
- VL53L0X по I²C;
- BH1750 по I²C;
- LSM6DS3 по I²C.

## Подключение этой версии

| Сигнал / устройство | GPIO / адрес |
|---|---|
| SDA | GPIO8 |
| SCL | GPIO9 |
| OLED | `0x3C` |
| BH1750 | `0x23` |
| VL53L0X | `0x29` |
| LSM6DS3 | `0x6B` |

Перед подключением проверьте маркировку и распиновку конкретных модулей.

## Библиотеки

- U8g2;
- Adafruit VL53L0X;
- BH1750;
- SparkFun LSM6DS3.

## Запуск

1. Откройте `DeskBot_v03.ino` в Arduino IDE.
2. Установите перечисленные библиотеки.
3. Выберите ESP32-S3 и скорость Serial `115200`.
4. При включении не двигайте робота во время калибровки LSM6DS3.
5. Соберите и загрузите скетч.

## Настройка

Пороги датчиков и длительности находятся в `Config.h`. Основные параметры:

- `IMU_MOVE_ACCEL_DELTA_G`;
- `IMU_MOVE_GYRO_DPS`;
- `IMU_PICKUP_CONFIRM_MS`;
- `IMU_PICKUP_MOTION_GAP_MS`;
- `IMU_SHAKE_ACCEL_DELTA_G`;
- `IMU_SHAKE_GYRO_DPS`;
- `HAPPY_DISTANCE_MM` / `CURIOUS_DISTANCE_MM`.

## Ограничения

- LSM6DS3 не измеряет высоту над столом; определение поднятия — настраиваемая IMU-эвристика.
- Пороги требуют проверки на собранном корпусе.
- Статус версии: `DEVELOPMENT`; это не финальная производственная прошивка.
