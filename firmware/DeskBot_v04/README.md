# DeskBot v04 — скука, ожидание и возвращение

Версия добавляет историю присутствия: DeskBot различает первое появление,
короткий уход и возвращение после долгого отсутствия. 

Связанный контент: [Telegram](), [Instagram](), [YouTube]()

## Поведение

- первое появление: `Curious → Happy → Content`;
- короткий уход: `Curious → Waiting`, при возврате `Happy → Content`;
- долгий уход: `Waiting → Bored`;
- возврат после скуки: `Offended → Reconciling → Content`, без повторного
  `Happy` и сердечек;
- `Content` и `Bored` меняют случайные реплики и плавные мини-анимации;
- периодические реплики показывают округлённое число минут в состоянии;
- IMU-реакции временно перекрывают лицо, не сбрасывая underlying behavior.

VL53L0X подтверждает присутствие объекта, а не распознаёт человека. Для
устойчивого перехода требуются три последовательных замера:

- не дальше 600 мм — presence;
- от 700 мм — absence;
- 600–700 мм — гистерезис без смены состояния.

Если после подтверждённого presence датчик перестал получать valid samples,
уход фиксируется после трёх невалидных замеров и непрерывного таймаута 1200 мс.

## Оборудование

- ESP32-S3;
- OLED SSD1306 128×64 по I²C;
- VL53L0X по I²C;
- BH1750 по I²C;
- LSM6DS3 по I²C.

## Подключение этой версии

| Сигнал / устройство | GPIO / адрес |
|---|---|
| SDA | GPIO8 |
| SCL | GPIO9 |
| OLED | `0x3C` |
| VL53L0X | `0x29` |
| BH1750 | `0x23` |
| LSM6DS3 | `0x6B` |

Перед подключением проверьте маркировку и распиновку конкретных модулей.

## Библиотеки

- U8g2;
- Adafruit VL53L0X;
- BH1750;
- SparkFun LSM6DS3.

## Запуск

1. Откройте `DeskBot_v04.ino` в Arduino IDE.
2. Установите перечисленные библиотеки.
3. Выберите ESP32-S3; для проверенного стенда использовались Flash 16 MB и
   OPI PSRAM.
4. При включении не двигайте робота во время калибровки LSM6DS3.
5. Соберите и загрузите скетч; откройте Serial Monitor на `115200`.

Пороги и длительности находятся в `Config.h`. Для съёмки меняйте constants,
не переписывая переходы state machine.
